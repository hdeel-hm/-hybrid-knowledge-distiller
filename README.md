# Hybrid Deterministic Knowledge Distiller | محرك تقطير المعرفة الحتمي

منظومة هندسية خفيفة لبناء قواعد المعرفة للشركات الناشئة وتقليل الاعتماد على واجهات الذكاء الاصطناعي المكلفة (LLM APIs) بنسبة تصل إلى **90%**.

---

## الفكرة الهندسية | Core Architecture
بدلاً من إرسال الكتب والمراجع الضخمة إلى نماذج الذكاء الاصطناعي في كل استعلام، يقوم النظام بـ **تقطير المعرفة لمرة واحدة** واستخلاص "الزبدة القابلة للبرمجة" وتخزينها محلياً، مع توجيه الطلبات للذكاء الاصطناعي فقط عند غياب المعلومة (`Smart Escalation`).

### المزايا التقنية والأدائية:
* **قراءة متدفقة لملفات PDF (`PyMuPDF Streaming`):** معالجة الكتب الأكاديمية صفحة بصفحة مع تحرير فوري للذاكرة (`Garbage Collection`) لإبقاء الاستهلاك تحت **40MB RAM**.
* **استخراج حتمي بدون هلوسة (`Zero-Hallucination Extraction`):** صيد المعادلات الرياضية، القواعد الشرطية المنطقية (`If/Then` - `إذا/فإن`)، والإحصائيات الموثقة باستخدام تعابير نمطية مترجمة مسبقاً (`Pre-compiled Regex`).
* **بحث نصي فائق السرعة (`SQLite FTS5` + `SHA-256`):** فهرسة محلية مدمجة تسترجع الإجابات في أجزاء من المللي ثانية وبتكلفة **$0.00**، مع منع تكرار التخزين عبر البصمة الرقمية.
* **بوابة API تفاعلية (`FastAPI`):** جاهزة للربط المباشر مع منصات الأتمتة (`n8n` / `Make`) أو تطبيقات الأعمال (`B2B SaaS`).

---

## هيكلية المشروع | Project Structure
* `vault_storage.py`: خزنة البيانات الدائمة ومحرك البحث `SQLite FTS5`.
* `distiller_core.py`: محرك قراءة الكتب وتقطير المعادلات والقواعد وفحص الروابط.
* `app.py`: بوابة `FastAPI` السحابية مع حماية `Rate Limiting`.
* `requirements.txt`: الاعتماديات الخفيفة للتشغيل السحابي.
